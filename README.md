# AI Prompt Playground

A simple AI Prompt Playground built with **HTML, CSS, and JavaScript** as part of my AI Engineering learning journey.

## 📌 About the Project

This project allows users to enter a prompt, submit it, and see the prompt displayed on the page.

The project focuses on practicing **JavaScript fundamentals and DOM manipulation**. It does not connect to an AI model yet.

## ✨ Features

* Enter a prompt using a textarea
* Submit the prompt
* Validate empty prompts
* Display an error message for empty input
* Display the submitted prompt
* Clear the error message after a valid submission
* Clear the textarea after submission
* Basic DOM manipulation and event handling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📚 JavaScript Concepts Practiced

* Variables (`const`, `let`)
* Data Types
* Operators
* Conditional Statements (`if/else`)
* Functions
* Function Parameters and Return Values
* DOM Manipulation
* `getElementById()`
* `.value`
* `.textContent`
* `addEventListener()`
